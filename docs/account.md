# My Account

Manage your login details, API keys and preferences. Open the page from **Setup > My Account**, or from the user menu at the top right.

## Account

Change **Username**, **Email** and **Password**. Click the edit icon next to each. Changing the email address or password needs your current password.

## API keys

Scripts and devices use an API key in place of your password.

- **Read & Write API Key**: read data and post data. Use it for devices and scripts that send data.
- **Read Only API Key**: read data only. Use it to share or embed data.

Click **Copy** to copy a key. Click **Generate New** to replace a key, for example if it has been shared by mistake. Devices and scripts using the old key stop working until you update them.

A device can also use a [device key](devices.md#device-key), which can only post to its own node.

## Profile

- **Timezone**: used for daily, weekly and monthly totals in graphs and apps. Set this first.
- **Language**: the interface language.
- **Starting page**: the page that opens after login.
- **Gravatar**, **Name**, **Location**: optional.

## Appearance

**Theme colour** and **Sidebar colour** are saved in this browser only.

## Delete account

**Delete account** removes the account with its inputs, feeds and data. Enter your password to confirm.

```{warning}
Deleting an account is permanent.
```
